# NIPAT 0.8.5 R reference

These six files are byte-for-byte copies from the published `v0.8.5` source
commit `eafadf7002a9c7d7c1b9af9ccafc47d698a059e5`. `manifest.json` records
their original repository paths and SHA-256 values. They are immutable test
inputs, not an alternative scientific engine selected by the application.

Keep the originals unchanged when editing candidate scripts. Differential
verification runs both versions in the same runtime with the same synthetic
inputs and compares their outputs. A baseline update requires a separate,
explicitly reviewed decision and must not hide a candidate regression.

The files retain their original authorship and licenses. See the
[DNPcall license](../../../scientific/vendor/DNPcall/LICENSE),
[NEWPAT license](../../../scientific/vendor/NEWPAT/LICENSE) and
[NIPAT notices](../../../THIRD_PARTY_NOTICES.md).

These references are development-only and are excluded from the installer
source allowlist and the scientific runtime's explicit COPY instructions.
